白底、細線、刻度、直接標值。每頁一句判斷，原生圖表的數字可在 PowerPoint 編輯。

此表的 px 是設計座標，不是螢幕 CSS px。HTML、列印 PDF、既有 Office 與獨立 SVG／PNG 的預設、來源及尺寸換算統一見[全交付字級索引](README.md#全交付字級索引)。

## 4. 刻度與來源列

- 來源列：一條 1 px #7F7F7F 細線，下掛 9 個刻度，首、中、尾為長刻度 14 px，其餘為短刻度 7 px；刻度下 14 px 為文字列。
- 文字列：左為 sources 各格（資料來源、單位、期間，必要時加「未提供」），格距 40 px，每格不斷行，放不下時整格換到下一行；右為頁碼「n / 總頁數」。沒有的格子整格刪除。
- 來源列最多兩行。兩行還放不下時，實作發出警告，字級不縮小。
- 圖表軸刻度：8 px，朝外，#7F7F7F；刻度值 24 px #4A4A4A，置中於刻度。
- 月份尺標：每月短刻度 8 px，每季長刻度 16 px。
- 數字格：頂線 1 px，左端掛 16 px 刻度。
- 全球藍章節尺標位於深藍底，目前段與其標籤用白色，其餘用 #BDCCED；保留目前段 4 px 與其餘 1 px 的粗細區別。
- 不使用 01／02／03 編號、不使用「EXHIBIT」類標籤。

## 5. 標註規則

1. 直接標值：數值寫在長條末端外 10 px、點旁 16～18 px、線尾 16 px。能直接標就不用圖例。
2. 折線不用圖例，名稱與末值寫在線尾。
3. 只有一個重點時，重點的值與標籤用 #28317B 粗體 600，其餘 #111111／#4A4A4A。
4. 增減一定照實帶全形符號「＋」「−」；顏色依好壞決定（見第 6 節「增減上色」）。
5. 單位寫在來源列；軸上只在軸尾寫單位（例如「分鐘」「車柱數」）。
6. 預估值與「其他」的填色依輸出方式而定：

| 項目 | SVG 輸出 | 原生圖表 |
|---|---|---|
| 預估值 | 白底＋ 45° #28317B 細斜線（1.5 px，間距 7 px），外框 1 px #28317B | #9DB1D9 實色，標籤加「預估」 |
| 其他 | 白底＋ 45° #DDDDDD 斜線（2 px，間距 7 px） | #DDDDDD 實色 |

7. 長條一律從 0 起算；不截斷軸。
8. 2×2 矩陣：優先象限用淡底 #F6F6FA。
9. 表格：數字靠右；強調列用淡底 #F6F6FA＋粗體；合計列上方 1 px #111111。

## 6. 色彩職務

| 職務 | 色碼 | 用法 |
|---|---|---|
| 文字 | #111111 | 內文、數值 |
| 次要文字 | #4A4A4A | 標籤、來源、頁首、沒有變化的增減 |
| 格線 | #E3E3E6 | 格線、表格列線 |
| 灰 | #7F7F7F | 軸線、刻度、非重點資料 |
| 封面標題 | #000066 | 白底封面大標 |
| 標題 | #000099 | 白底內容頁標題 |
| 深色底 | #142979 | 章節頁；上面的字用 #FFFFFF 與 #BDCCED |
| 淡底 | #F6F6FA | 強調列、優先象限 |
| Focus | #28317B | 一張圖只有一個重點時；其餘用 #7F7F7F |
| Ordered | #9DB1D9 #8A9CCB #7285BB #4B5A9C #28317B | 有先後或強弱，由淺到深 |
| Categorical | #28317B #04696C #6A9A3A #B57FCF | 真正無序的類別，最多 4 色 |
| 其他 | #DDDDDD | 名稱為「其他」的類別 |
| 變好／變差 | #015224／#9D2324 | 只用在增減標籤；顏色依好壞，不依正負號 |

選色順序：

1. 只有一個重點 → Focus＋灰。
2. 時期比較（去年／今年、前／後） → Ordered 兩階：舊 #9DB1D9、新 #28317B。不用不同色相。
3. 有序等級、階段 → Ordered 由淺到深，取連續的階。
4. 無序類別 → Categorical 依序取色，超過 4 類的合併為「其他」。
5. 同一個類別在整份簡報的每張圖都用同一個顏色（例如「通勤」在每張圖都是 #28317B）。
6. 「其他」看類別名稱決定，不看排在第幾個：名稱為「其他」就用 #DDDDDD，即使它是第 2 類。

增減上色：

1. 每個資料系列有欄位 `better`：`higher`（越高越好，預設）或 `lower`（越低越好）。
2. 符號照實寫：數值增加寫「＋」，減少寫「−」。
3. 變好（`higher` 時增加、`lower` 時減少）用 #015224；變差用 #9D2324。
4. 例：等待時間 `better: lower`，「−4.6 分鐘」用深綠；收支比 `better: higher`，「−0.04」用深紅。
5. 邊界情況：
   - 增減色只用在增減標籤；系列本身的顏色照職務規則。
   - 沒有前期值：不寫增減。
   - 前期是 0：只寫差額，不寫百分比。
   - 沒有變化：寫「±0」，用 #4A4A4A。
   - 百分比之間的變化寫「個百分點」，例如「＋2.1 個百分點」，不寫「%」。

色塊上的文字由引擎依實際填色選擇可讀的黑／白文字；深藍章節固定用 #FFFFFF 與 #BDCCED。以 `node scripts/check-design.js` 檢查對比，再看實際成品。Ordered 與 Categorical 保留既有對比度與色盲區辨調整，不回退舊色階。

## 7. 資料顯示

1. 0 是觀察值：照常畫出並標值（例如長度 0 的長條標「0」）。
2. 缺值不畫，也不補 0；來源列加一格「未提供：項目名」，例如「未提供：北岸區 3 月」。
3. 非零值在顯示精度下會捨成 0 時，標籤寫「<0.1」或「>−0.1」（依顯示精度，例如精度 1 時寫「<1」）。
4. 標籤只做格式化，資料保留原值；原生圖表的資料表寫入原值。

## 8. 版型

簡報檔欄位：kicker（頁首章節名）、claim（一句判斷）、note（補充或結論）、visual（圖表或表格）、sources（來源、單位、期間）。欄位空著時整格不出現。

| 版型 | 內容 | 用到的欄位 | 背景 |
|---|---|---|---|
| 封面 | 單位、日期、主標（兩行）、副標 | kicker（單位）、claim（主標）、note（副標）、sources | 白 |
| 章節 | 章節名、說明、章節尺標 | kicker、claim（章節名）、note（說明）、sources | #142979 |
| 一句話 | 一句大字判斷（只有一處 Focus）、一行補充 | kicker、claim、note、sources | 白 |
| 證據 | 標題＋一張圖或表＋結論欄 | kicker、claim、visual、note（結論）、sources | 白 |
| 數字 | 2～4 個關鍵數字，含增減 | kicker、claim、visual（數字格）、sources | 白 |
| 比較 | 2～3 個方案，建議方案 4 px 藍頂線 | kicker、claim、visual（比較表）、sources | 白 |
| 步驟 | 階段列＋月份尺標時間軸 | kicker、claim、visual（時程）、sources | 白 |
| 收尾 | 下一步、負責人、期限 | kicker、claim、visual（行動表）、sources | 白 |

每頁都有來源列與頁碼。

熱度格：五階用等寬分箱，從 0 到資料最大值等分五段，每段含下限、不含上限，最高一段含上限；圖例寫出各階範圍（例如 0–2、2–4、4–6、6–8、8–10）。
